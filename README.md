# 🤖 Linux System Bot (Bash)

Un assistente interattivo a riga di comando sviluppato in **Bash** per monitorare le risorse e lo stato del sistema operativo Linux.

---

### 🚀 Funzionalità
Il bot mette a disposizione un menu interattivo che permette di eseguire rapidamente le seguenti operazioni:
1. **Controllo Spazio Disco:** Verifica l'occupazione e lo spazio libero delle partizioni (`df -h`).
2. **Monitoraggio Memoria:** Mostra lo stato in tempo reale della RAM e della memoria di swap (`free -h`).
3. **Chiusura Sicura:** Termina l'esecuzione dello script in modo pulito.

---

### 🛠️ Prerequisiti & Tecnologie
* Sistema operativo **Linux** (testato su Ubuntu).
* **Bash** (Bourne Again SHell).
